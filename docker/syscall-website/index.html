# FRONTEND INTEGRATION GUIDE

1. INSTALLATION & PREREQUISITES

Include Ethers.js v6 and Syscall SDK in your HTML head:

<script src="https://cdnjs.cloudflare.com/ajax/libs/ethers/6.11.1/ethers.umd.min.js"></script>
<script src="https://syscall-sdk.com/syscall-sdk.js"></script>

2. SENDING AN EMAIL

Triggers a blockchain transaction signed by the user:

const syscall = new Syscall(window.ethereum); // Signature: (destination, subject, senderName, content) const receipt = await syscall.sendEmail( "alice@example.com", "Governance Alert", "DAO Protocol", "Your proposal #42 has passed." ); console.log("TX Hash:", receipt.txHash);

3. SENDING AN SMS

ETH cost is calculated based on message length:

const syscall = new Syscall(window.ethereum); // Signature: (phoneNumber, content) const receipt = await syscall.sendSMS( "+33612345678", "Security Alert: Login detected." ); console.log("SMS Sent! TX:", receipt.txHash);

DEVELOPER NOTES

  • • Network: User must be on the supported chain (configured in Relayer).
  • • Cost: The pay() method is payable; ETH is deducted from wallet.
  • • Async: Execution waits for 1 block confirmation.
# BACKEND INTEGRATION GUIDE (NODE.JS)

1. SETUP & AUTHENTICATION

1. Install npm dependencies (ethers, dotenv).
2. Download syscall-sdk.js manually (same file as frontend) and place it in your root.

# Terminal npm install ethers dotenv # Note: Do NOT install syscall-sdk via npm. Download the file directly.
// app.js require('dotenv').config(); // Import the local downloaded file const Syscall = require('./syscall-sdk'); // Backend Init requires a Private Key (NOT a provider) const syscall = new Syscall(process.env.PRIVATE_KEY);

2. TRIGGERING ALERTS (EMAIL)

Ideal for cron jobs or server monitoring:

async function notifyAdmin() { const receipt = await syscall.sendEmail( "admin@syscall-sdk.com", "System Alert: Server Down", "Infrastructure Bot", "Critical error on node #4." ); console.log("TX Confirmed:", receipt.txHash); }

3. SENDING OTP (SMS)

Send verification codes directly from Node.js:

async function sendOTP() { const receipt = await syscall.sendSMS( "+15550123456", "Your verification code is: 8492" ); console.log("SMS TX Hash:", receipt.txHash); }

BACKEND DEVELOPER NOTES

  • • Gas Management: Backend wallet must hold ETH for Gas + Service Fee.
  • • Latency: Dependent on block time (~12s Mainnet). Not for real-time loops.
  • • Concurrency: Handle nonces carefully when sending rapid parallel requests.
